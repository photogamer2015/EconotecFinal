{% wa_ico %} EconoBot por código QR (sin API)

{% if not wa_activo %}Apagado {% elif wa.estado == 'conectado' %}Conectado{% if wa.numero %} · +{{ wa.numero }}{% endif %} {% elif wa.estado == 'esperando_qr' %}Falta escanear el QR {% else %}Desconectado{% endif %} {% ico 'plug' %}Conexión {% if wa_activo %}Ver chats{% endif %}
  1. Llega un mensaje al WhatsApp vinculado: se crea el cliente y su oportunidad, asignada a una asesora.
  2. El bot responde solo: bienvenida con el menú de categorías, respuestas por palabra clave (precios, horario, pagos…), anota el equipo y la falla («laptop HP, no prende») y agenda una llamada si el cliente dice «sí».
  3. Pasa a una asesora cuando el cliente escribe «asesor» o cuando una asesora responde desde Chats de WhatsApp: el bot se calla en ese chat.

Sin el QR conectado, las asesoras siguen abriendo cada chat con un clic (enlace wa.me) como antes.
